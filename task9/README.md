# Мини-графический редактор

## 1. Название и описание задачи
    Программа представляет собой мини-графический редактор, демонстрирующий основные принципы ООП. Программа позволяет создавать различные геометрические фигуры (круги и квадраты), управлять их координатами и вычислять общую площадь всех фигур в одном цикле.

## 2. Архитектура проекта

  Инкапсуляция: Данные _x, _y, _radius, _side скрыты. Доступ к ним только через публичные методы (get_coords, set_coords, get_radius, get_side).
  Наследование: Базовый класс Figure хранит общие координаты. Классы Circle и Square наследуются от него, добавляя свои уникальные свойства.
  Полиморфизм: Оба класса имеют метод calculate_area(). В цикле взывает единый метод для разных объектов, не проверяя их тип через if/else.

## 3. Пример использования

shapes = [
    Circle(10, 20, 5),
    Square(30, 40, 6),
    Circle(50, 60, 7),
    Square(70, 80, 8),
    Circle(90, 100, 9)
]
print("Фигуры")
for shape in shapes:
    shape.display_info()
total_area = 0
for shape in shapes:
    total_area += shape.calculate_area()
print(f"Общая площадь всех фигур: {total_area:.2f}")
